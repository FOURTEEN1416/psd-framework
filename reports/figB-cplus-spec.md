# C+ 全局规格（figB 阶段 II · 六图全重画）

> 适用于 fig1/fig2/fig3/fig4/fig5/GA 六图重画。在方向 C「分阶色标 + 制图精度」基础上更激进地减层。

## 1. 笔触（更细一档）

| 元素 | C（当前） | **C+（本轮）** |
|---|---|---|
| spines left/bottom | 0.6 | **0.4** |
| tick width | 0.6 | **0.4** |
| tick length | 2.2 | **1.8** |
| 主流线（流程/连接） | 1.6 | **1.2** |
| 虚线（语义回路） | 1.0 | **0.7** |

## 2. 字号阶梯（更大跳幅）

| 层级 | C | **C+** | weight |
|---|---|---|---|
| 顶标题（流程图面板标题、GA 主标） | 6.8 | **8.0** | bold |
| 副标题（子区、轴名、图级图例） | 6.0 | **6.5** | regular |
| 正文（卡片标题、系列直标） | 5.5-5.9 | **5.8** | regular |
| 注释（own full budget、pre-registered band） | 5.5 | **5.8** | regular |
| 段内最小（chip、write-back、面板 a/b/c 字母） | 5.5 | **5.5（保）** | regular |

字号底线：**5.5pt**（D3 强制）。

## 3. 留白（更大气）

- 画布高度普遍 +0.2-0.4 in（不增宽，遵守 \linewidth 约束）
- 卡/面板**内部 padding +20-30%**（与字号增大匹配）
- subplot hspace/wspace +0.05-0.1
- 图内区块两两净空从 2px → **3px**

## 4. 描边（弱化）

- **非焦点卡：去 0.55-0.6pt 描边**（v8 v18 时期用），C+ 改为**仅靠色阶分层**（同色相浅填 mix 0.70-0.78，无 edge）
- **焦点卡：仍保留深填块 + 白字**，但单图焦点块 **≤1**（之前允许 ≤2，本轮更克制）
- 虚线**只用于一种语义**（演化回线 / Taxonomy 约束回路 / 预注册边界）

## 5. 颜色（不变色板，更克制）

- **不改 psd_style 任何 token 数值**（D1 不触动）
- 更频繁使用浅阶层（mix 0.78-0.85）作为"非焦点"底色
- 取消饱和中色填块——中阶颜色仅用于：数据曲线、误差棒、焦点字

## 6. 数据与图型（不变）

- 数据零改动（D2 不实施）
- caption 不动
- 图号不重排
- 冻结清单原样保留

## 7. GA 例外（D5 修复）

- 531×131pt 硬上限不变
- 笔触按上表细化
- 字号：主标 8.0 → **9.0**（GA 单图需要更突出）；其余按表
- **D5 修复**：dashed 演化回线的上行箭头不再指向 Φ（frozen）。改为：从 Ω 底部下行 → 横向贯穿下方 → 在 Ω 下方右侧回入 Ω。视觉 = "Ω 自反馈 / Ω 自重训"，与 "only Ω retrains" 语义对齐。
