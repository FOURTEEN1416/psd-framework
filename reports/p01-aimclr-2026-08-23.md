## 2. ⚠️ 口径决策披露（用户可否决）

InterPet4D v1 **无行为标注**（官方 README 证实：纯动捕数据集），交接文档预期的"kNN 行为分类"不可直接执行。本报告采用：

- **probe 标签 = 文件名内嵌 dog ID（12 类个体识别代理 probe）**
- 随机基线按实际类别数 = 100/12 ≈ 8.33%（修正交接文档的 4.5%/22 类 K9 合成口径引用）
- 该指标衡量表征的**个体区分能力**（自监督质量探针惯例），不是行为识别精度

若需改用行为标签源（如 Animal Kingdom 行为标注，需跨域关节对齐工程），预训练权重可直接复用，仅重跑评估。

## 4. 表征坍缩事故与根因（重要工程记录）

初版训练 loss 精确平台于 **2·log(queue_size)**（三路 softmax 全均匀 = 完全坍缩）。诊断实验链：

| 实验 | 变量 | 结果 |
|------|------|------|
| E1 | randn 假数据 | 同样平台 → 与数据无关 |
| E2 | 关闭 shear | 同样平台 → 与增强无关 |
| E3(A/B/C) | lr / queue / momentum 扫描 | 平台值随 queue_size 变化（2logK），均坍缩 |
| 探针 | checkpoint 特征 | 余弦相似度恒 1.0000（同方向输出） |
| E4/E6 | 手写循环（默认初始化） | **正常学习**（sim 1.0→0.14） |
| **E7** | 手写循环 + 复刻官方 weights_init | **坍缩复现，Adam 也无法逃逸** |

**根因**：官方 `PT_Processor.load_model` 的 `weights_init` 将全部 Conv/Linear 权重覆盖为 N(0, 0.02)，前向信号逐层衰减使表征落入 InfoNCE 无法逃逸的 cone。与本仓数据、增强、优化器、GPU、torch 版本均无关。

**修复**（零改动 external/）：`psd/training/p01_processor.py` 子类跳过该初始化，其余官方逻辑原样继承。

## 7. 一条命令复现序列

```powershell
# 0) 环境（一次性；torch 系经本地复制安装，见 HANDOVER 补充说明）
py -V:3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 1) 导出数据（K9 盘点路径）
.\.venv\Scripts\python.exe scripts\export_interpet4d.py --target-t 64

# 2) 自监督预训练（120 epoch，RTX 5060 约 13 分钟）
.\.venv\Scripts\python.exe scripts\train_aimclr.py

# 3) kNN 验收评估（JSON 归档 reports/）
.\.venv\Scripts\python.exe scripts\eval_aimclr.py --knn --out reports/p01-knn-result.json

# 4) 加载器单元测试（可选）
.\.venv\Scripts\python.exe -m pytest psd\data\tests -q
```
