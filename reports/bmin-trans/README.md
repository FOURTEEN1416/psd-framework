# B-MIN-TRANS — 不对称标注 taxonomy 迁移实验（单一汇总页）

> 本目录 = B-MIN-TRANS 实验的唯一汇总地（设计/迭代/判定/工件全在此）。
> 代码: `scripts/make_rule_seeds_ntu_bmin.py`(v0-v2) + `scripts/bmin_trans_v3_calib.py`(v3 终版)
> 状态: **✅ 终版判定已出（2026-09-11）— 精度线 FAILS，成本线 PASS**

## 1. 一句话设计

NTU60 60→49 迁移（复用 TRANS-002 冻结迁移），三臂标注单位不对称：
**D 臂只吃规则种子（0 人工 clip 标签）** vs **C 臂全量重标注（TRANS-002 耦合臂，79.8%）** vs M 臂（匹配求解器，82.6%）。

## 2. 终版判定（v3, 2026-09-11）

| 判据 | 结果 | 判定 |
|------|------|------|
| 标注成本线 | D=0 人工 clip 标签（规则+4k dev 校准）vs C=40,091 clip 全量重标注 | **PASS（≈∞节省）** |
| 墙钟线 | D=CPU 分钟级 vs C=9897s median | **PASS（>3×）** |
| **精度线** | **D=14.55% vs C=79.8%（gap −65.25pp）** | **FAILS** |
| 种子质量 | 覆盖 76.85%、精度 19.06%（≈9.5× 随机）；27/49 类有桩 | 门内(v3.1 弱监督门) |

**科学解读**：规则种子（公开类名语义+几何先验，4k dev 校准的决策桩）不足以替代标签恢复——
"taxonomy 演化只需规则种子零标注更新"的最强形式在本工作点被定量否定；同时把论文 L9/L11
（标签恢复才是机制）从论断升级为带数字的边界实测。披露：决策桩在 4k 标注 dev 集上程序化校准
（披露式修订，D 臂训练本身零人工标签）；规则=单特征决策桩（可解释），更强规则引擎属未来工作。

## 3. 迭代史（教训链）

| 版本 | 特征 | 结果 | 死因/结论 |
|------|------|------|-----------|
| v0 | 2D 误读(竖轴判错) | 精度 2.2%≈随机 | 格式错误，非结果 |
