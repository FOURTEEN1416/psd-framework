# Figure pack — Anchor Recycling (next paper)

All four figures are generated by a single script, `scripts/p1_sprint/make_next_paper_figures.py`,
which loads every value from the run summaries and asserts it against the numbers
reported in the manuscript. Nothing is typed by hand twice.

```bash
.venv/Scripts/python.exe scripts/p1_sprint/make_next_paper_figures.py
```

## Design system

Palette copied from the A-题 submission (`D:/Desktop/A题提交.zip`), i.e. the
`summer-beach-v6` fill palette in `paper-figure-palette` — light, warm/cool
pastel fills with same-hue ink for lines and text.

| Element | Value |
|---|---|
| Typeface | Arial / Arial Bold (Type 42 embedded), 7.4–9.2 pt at final size |
| Method fill | pale cyan gradient `#E8F8FF` → `#6FCDFD` |
| Method ink | slate teal `#307697` / `#3F6B83` (measured stroke colours in the A-题 PDF) |
| Reference / frozen | `#BFBFBF` line, `#808080` markers |
| Text colours | blue `#1F4E79`, orange `#B35900`, green `#2E6B4E`, grey `#808080` (measured text colours) |
| Coral accent | `#C74C53` (measured stroke) |
| Grid / track | `#BFBFBF` grid at 55%, `#F2F4F7` track |
| Figure size | 165 × 78 mm (Fig. 1), 165 × 82 mm (Fig. 2), 110 × 82 mm (Fig. 3), 110 × 78 mm (Fig. 4) |
| Export | vector PDF + 300 dpi PNG; no in-figure titles |

The first extraction pass used the palette skill's **deepened ink map** (`#19667F`, `#BE4E30`),
which is why it still read dark. The values above are the colours actually measured in the
A-题 PDF: stroke colours from `page.get_drawings()` and text colours from
`page.get_text("dict")` spans (`#1F4E79` 10.8k chars, `#B35900` 28.0k, `#2E6B4E` 12.6k, `#808080` 10.2k).

The palette is a **fill palette** (white-background contrast 1.2–2.1:1), so
lines, edges and text always use the same-hue ink colours above; category
distinctions additionally carry markers/line styles/direct labels (second
encoding), per the palette skill's rules.

## Figure-by-figure provenance

### Fig. 1 — `fig1_four_tier_gradient`
* Claim: budget retention degrades monotonically with reference quality.
* Data: NTU60 uses the published tier-1 protocol values (90.70% retention,
  74.45% reference); PanAf500 / NTU120 / UCF101 from
  `runs/p1_sprint/labelfree_panaf500|ntu120|ucf101/summary.json`
  (82.50 / 74.96 / 51.09), with denominators from the same summaries.
* Encodings: one bar per tier = 10-seed retention on a 0–100 track; the grey
  "ref" line under each tier name = full-label linear-probe accuracy (the
  retention denominator, not plotted as a bar); vertical lines = 85/90 thresholds.
* Statistics: retention = mean of per-seed budget-pipeline accuracy / full-label
  linear-probe accuracy; 10 seeds (42–51). Bands: CONFIRMS ≥ 90%, PARTIAL 85–90%.

### Fig. 2 — `fig2_tier_main_results`
* Claim: recycling the same anchors into encoder and semantic layer lifts every
  weak-reference tier; the size of the lift grows as reference quality degrades.
* Data: per-seed `retention_seed` from `adapt_t4_ntu120/summary_aug8_lr2e2.json`,
  `adapt_t4_panaf500/summary_aug4.json`, `adapt_t4_ucf101/summary_same10.json`;
  frozen seeds from `b_arms / full_ref` in the corresponding `labelfree_*` summaries.
* Encodings: three panels (a/b/c); thin grey lines = individual seeds, thick
  teal line = frozen → recycled mean; coral text = gain in pp; verdict tag at
  the panel top right.
* n = 10 seeds (42–51) per mean; means use the reported ratio-of-means retention,
  which differs from the mean of per-seed ratios by < 1 pp (asserted in the script).
  Per-seed values are tabulated in the released summaries and discussed in §4.3.

### Fig. 3 — `fig3_budget_allocation`
* Claim: the dual-use advantage widens monotonically with anchor budget.
* Data: `adapt_t4_ntu120/summary_ref5.json` (5% frozen), `labelfree_ntu120`
  (10% frozen), `summary_ref15.json` (15% frozen), `summary_split5.json` (5% dual),
  `summary_same10.json` (10% dual), `summary_dual15.json` (15% dual).
* Encodings: grey circles = semantic-only; navy squares = anchor recycling;
  shaded ribbon = gain; navy numbers = recycling retention; red numbers = gain in pp.

### Fig. 4 — `fig4_aug_dose_response`
* Claim: the augmentation dose–response is unimodal, peaking at V = 8.
* Data: `summary_same10.json` (V=1), `summary_aug4_lr2e2.json`,
  `summary_aug8_lr2e2.json`, `summary_aug12_lr2e2.json` — all NTU120, lr 2e-2,
  10 seeds.
* Encodings: boxes = interquartile range over ten seeds, dots = individual seeds,
  coral line = mean across doses; V = 12 is a single-seed probe (open diamond,
  labelled n = 1); dashed line = 85% PARTIAL threshold.
