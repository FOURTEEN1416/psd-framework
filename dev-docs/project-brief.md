# Project Brief — PSD-Framework（物理-语义解耦低资源行为识别框架）

> Truth source: 承接自 k9-training-system 立项研讨 + 7 方向 37 仓库调研结论（见 `research/`）
> 状态: ✅ 已确认（v1.0，2026-08-23 独立建仓）
> 上游决策: `k9-training-system/dev-docs/decisions/0013-research-repo-split.md`

## 1. 项目概述

**项目性质**：学术研究项目——物理-语义解耦的低资源动物行为识别框架。

**终极野心**：构建"适应动态业务逻辑的视觉基座系统"——物理层（骨架怎么动）与语义层（行为叫什么）解耦；评估标准演化时只改语义层、不动物理层；小样本自监督数据飞轮持续供数（上游 ADR 0012）。

**论文目标**：
- **Title**：A Physics-Semantics Decoupled Framework for Low-Resource Animal Behavior Recognition under Evolving Evaluation Criteria
- **目标期刊**：Pattern Recognition（IF≈8）/ IJCV
- **核心创新候选**：图像域小样本伪标签方法（姚青 JIA：VFM 骨干 + 锚点学习 + 聚类 + 伪标签）迁移到**时序骨架域**，结合 AimCLR（AAAI 2022）+ SMQ（ICCV 2025）+ TCL（CVPR 2021）；"首次"主张待 GitHub-First 检索核验

**方向五层图（2026-08-23 用户口径）**：

| 层 | 内容 | 归属 |
|----|------|------|
| ① 基座愿景 / ② 论文 / ③ P0 数据解阻 | 发论文实现终极野心的**研究线** | **本仓库** |
| ④ K9 产品系统 / ⑤ Phase 4 升级（LLM 解释器 + Mamba 产品化） | 产品系统**升级线** | k9-training-system |

> **Mamba 双角色备注**：产品替换在 K9 仓库推进；其合成基线（85.61%）作为本仓库论文实验的骨干候选复用。

## 2. 当前交付（P0 数据解阻，3-4 周）

1. **论文级方法论管线**：规则种子 → AimCLR → SMQ → 姚青 JIA 迁移 → TCL → 主动学习 → 骨干微调
2. **训练模型**：按合成 / 公开真实 / 真实 K9 三层指标口径评估 22 类行为分类
3. **论文初稿**（Pattern Recognition / IJCV）

真实 K9 视频不是启动硬依赖。

## 3. 非目标（显式排除）

- ❌ 不在本仓库开发任何产品功能（API / 前端 / RBAC / 评分报告归 K9 仓库）
- ❌ 不做云端部署、不做实时推理
- ❌ 不做基地视频采集（用公开数据）
- ❌ LLM 解释器属 K9 产品线议题，与本仓库无关
