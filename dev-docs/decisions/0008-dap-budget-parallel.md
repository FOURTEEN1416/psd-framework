# ADR 0008 — P2/P3 并行立项：APTv2 域自适应预训练骨干 + 种子预算曲线定位

> 状态: **Accepted（用户 2026-09-05 裁决"同步进行"两线 + 追问"是否胎死腹中"）**
> 日期: 2026-09-05 | 关联: ADR 0007（P1 NULL）、`docs/paper/dap-aptv2-preregistration.md`（PSD-DAP-PREREG-001）、`docs/paper/budget-curve-preregistration.md`（PSD-BUDGET-PREREG-001）

## 背景

P1（标签对齐门控）NULL 后诊断收敛：约束在**种子锚定的特征几何**（r0 原型精度 ~0.30 封顶），非门控规则。用户令并行两线：P2=换更强骨干（APTv2 无标签池域自适应预训练，直击特征质量约束）；P3=种子预算曲线（定位膝点，回答"本管线在犬科层到底需要多少标注才可用"）。

## 判定"论文胎死腹中？"——否

存活脊柱：C1 解耦成本 ≥3×（full 档 6.07× 实证）、C3 双证据线（kNN 2.51× + 四档梯度）、C4 分割预注册三门、C5 锚点聚类、**E9 跨域 NTU 90.6% 过预注册线（更严协议下存活）**、NTU 等价性 77.97%、预注册纪律+诚实负边界的信誉资产。死亡的仅是"犬科层 13% 端到端"单一主张。35-45% 录用概率高于期刊基线（10-20%）。P2 若 RESCUE 则主张复活升级；P3 无论结果都产出"低资源可用性边界"的可发表刻画。

## 决策

- **P2（PSD-DAP-PREREG-001）**：ST-GCN+BC 骨干（Y_CKPT 起点）在 503 条 APTv2 canidae 无标签骨架 clip 上做两视图 InfoNCE 续训（时间裁剪+关节抖动增广，GT 无关），再以 R16 修正协议 + P1 最优 V2 臂重跑 AK v1 spc2×10seeds。判据沿用 P1 冻结线（RESCUE≥20%&胜8/10 vs P1-V2 14.11%；PARTIAL 15-20；NULL<15），**不挪门柱**。保真自检：DAP 特征全监督参照 <30% 即判灾难遗忘，结果按边界解读。L9 先验（AdaBN 不足）如实引用——P2 是表征级更强干预，非重复。
- **P3（PSD-BUDGET-PREREG-001）**：描述性刻画（无通过/失败判据），V0+V2 × spc∈{2,3,4,6,8,12} × 10 seeds，报告均值/保留率/膝点（首个 mean≥24%=70% 保留的预算）。若膝点 ≤20%（spc≤3），任何主张复活须另立**验证性**预注册并经用户裁决（探索性→验证性分离，禁同一数据既找又证）。
- 两线并行：P3 纯 CPU 分钟级先跑；P2 GPU SSL 十分钟级。

## 后果

新增 `scripts/run_p16_dap.py`、`scripts/run_p17_budgetcurve.py`、`psd/training/dap_infonce.py`（新模块，不动既有骨干代码）。无论成败，E7 段的"边界"叙事获得定量刻画（P3）或候选救援（P2）；全 NULL 则论文以现脊柱投稿，P2/P3 入 §5 强化机制诊断。
