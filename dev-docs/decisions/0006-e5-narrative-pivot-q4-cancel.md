# ADR-0006 — E5 叙事换轨 warm-start 可用性 + Q4 叫停

> 状态: ✅ 已裁决并执行（2026-08-25 晨，用户醒后双拍板）
> 关联: ADR-0005（A2 warm-start 协议采纳）、`reports/w23-p05-al-warmstart-2026-08-25.md`、W18 任务书队列

## 裁决 1：E5 叙事换轨（选项 A）

**背景**：两轮实验（W14 冷启动 + W23 强打分器 warm-start）一致表明合成偏移层上不确定性采样无效率优势——"效率曲线"叙事拿不到正证据；但 W23 的 warm-start 协议把 b=20 基线从 ~7.8% 抬到 **82.0%**（b=200 达 95.7%），且两次独立执行逐字节一致。

**用户裁决**：采纳歆歆推荐方案 A——E5 正证据路径换轨为 **"warm-start 语义层初始化使小标注预算可用"**；类间轮转熵等混合策略降为 future work 一句话，不再开实验线。

**执行落点**：
- `docs/paper/experiment-skeleton.md` E5 节 v0.7 换轨块
- `docs/paper/outline.md` C7 行改写新主张与证据列
- 效率主张正式关闭（正文/摘要禁用维持）；负结果以探索性发现进 §5

## 裁决 2：Q4 叫停

**背景**：W23 排队的 full-budget 方向稳定性终验预期维持负结果，归档价值边际。

**用户裁决**："叫停省时"。Q4 从 W18 队列划除（任务书已标注取消理由）；如未来需要由新任务书重启。
