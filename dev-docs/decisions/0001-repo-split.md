# ADR 0001 — 从 k9-training-system 拆分独立研究仓库

- 状态: ✅ 已确认
- 日期: 2026-08-23
- 决策人: 用户
- 上游对应: `k9-training-system/dev-docs/decisions/0013-research-repo-split.md`

## 背景

上游项目 2026-07-26 至 08-20 经历 5 次方向演进，最终定调"学术研究为主，产品为副产物"。用户对方向的最终理解：**④ K9 产品系统与 ⑤ Phase 4 升级属于产品升级线；① 基座愿景、② PR/IJCV 论文、③ P0 数据解阻属于研究线**，服务于"发论文实现终极野心（适应动态业务逻辑的视觉基座系统）"。

两条线交付节奏（论文快迭代 vs 产品稳定性）、代码风格（实验脚本 vs 工程）、开源要求（投稿 code release）完全不同，继续同仓互相拖累。

## 决策

AI 曾推荐"先内后外两步走"（研究代码先留上游仓库 research/ 目录，投稿前再拆）；用户权衡后选择**立即独立建仓**：新建 `psd-framework` 仓库完整承载研究线与终极野心，不接受过渡态。

## 范围边界

| 归属 | 内容 |
|------|------|
| 本仓库 | ① 基座愿景 ② 论文（PR / IJCV）③ P0 数据解阻管线（P0.1-P0.6） |
| 上游 k9 仓库 | ④ K9 产品系统（Phase 1-3 冻结为验证平台）⑤ Phase 4 产品升级（LLM 解释器 / Mamba 产品化） |

## 资产策略

- 调研文档**复制**到本仓库 `research/`（5 份），上游原件冻结存档
- 代码资产（ST-GCN+BC 训练栈 / Mamba 基线等）**暂不搬移**；各子阶段启动时按 `docs/assets-map.md` 显式移植，移植后以本仓库测试为准
- 数据文件留本地原位，磁盘路径登记 `docs/DATA_LOCATIONS.md`（待盘点）
- 跨仓只允许文档指针，禁止跨仓 import

## 后果

- 正面：论文开源干净；研究迭代不受工程约束；基座泛化（超出犬类/行为域）有独立载体
- 代价：跨仓复用需显式移植 + 重验；单人双仓管理成本上升
