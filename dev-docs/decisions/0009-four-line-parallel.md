# ADR 0009 — P2′/P5/P6/P7 四线并行：数据优化+第二跨域+真K9标注+共享基准调研

> 状态: **Accepted（用户 2026-09-05 裁决"四个部分并行全力冲击"）**
> 日期: 2026-09-05 | 关联: ADR 0007/0008（P1/P2/P3 三向否证后，转向数据质量+泛化验证）

## 背景

P1(门控)/P2(骨干)/P3(预算) 三杠杆三角否证 AK 层端到端低资源可救援，瓶颈=数据质量。R21 统计审计修复跨层分母+标签粒度自矛盾后，论文达到无新数据前提下的最优状态（34页零错误，PR概率约30–40%）。用户令四线并行全力冲击天花板。

## 决策：四线并行

| 线 | 内容 | 判据（跑前冻结） | 可行性已验证 |
|---|---|---|---|
| **P2′ 数据优化** | SuperAnimal-Quadruped（DLC Model Zoo，Nature Comms 2024）重提取 AK 骨架→重建 full12→重跑 E7 | 天花板(33.93%全监督参照)上移→骨架质量是瓶颈可修；不动→确认瓶颈在标签对齐，负结果更强 | ✅ AK 视频 211 文件在 k9 仓盘上；SuperAnimal 模型公开（HF mwmathis/DeepLabCutModelZoo） |
| **P5 第二跨域** | Kinetics-Skeleton（ST-GCN 预训练权重公开）→ 冻结骨干 dump 特征 → 10% PSD 语义管线 vs 全预算线性参照 | 保留率 ≥85%→跨域双点确认；<85%→协议依赖性，诚实报告 | ✅ ST-GCN 预训练权重 GoogleDrive/BaiduYun 公开 |
| **P6 真K9标注** | 公开工作犬训练视频作为源 + 用户组织 K9 训练师双标注（κ≥0.60 门，PSD-K9-PREREG-001 条款不变） | 双标注 κ≥0.60 过门→进入管线；不过→增标或换视频 | ✅ 合规（不用抓取标签分发，只当视频源+自标注） |
| **P7 共享基准调研** | ASBAR/PanAf20K 数据开放性深挖；如开放→PanAf 上跑 PSD 管线对比 75.3% | 如数据可得→动物共享基准对比成立 | 调研中（vita-epfl repo 是人类数据管线非 ASBAR 本体） |

## 执行纪律

- 每线独立预注册协议，跑前冻结（commit 先于结果工件）。
- 零结果/负结果如实入 §5 或新 section，不筛选不丢弃。
- 判据不改（预注册条款不因结果移动门柱）。
- 零实验数字改动至已有正文（新结果入新 dated 工件→再回填）。
