# ADR 0007 — P1 立项：标签对齐伪标签修正机制（label-alignment force）

> 状态: **Accepted（用户 2026-09-05 裁决"立项！！！！冲！！！！！！！强化这个卖点必须"）**
> 日期: 2026-09-05 | 关联: review-log R16/R17、experiment-skeleton v2.0、`docs/paper/label-alignment-preregistration.md`（PSD-ALIGN-PREREG-001）

## 背景

R16 端到端协议诚信修正后，犬科公开真实层（AK full12）的 C6 低资源主张撤回为负边界：修正协议下 warm spc2 仅 9.8%±7.5（chance 11.1%），伪标签池精度 ~0.11。R16 工件给出精确失败机制：r0 原型路（种子锚定）池精度 0.30，头路接管后逐轮退化 0.20→0.17——18 个种子片段使 MLP 头过拟合→自信错判→κ 尺度错配下门控放行 ~80%→确认偏置坍缩；GT 无关的逐轮温度再校准（head_calib）不救（8.9–12.5%）。L9 诊断："缺的是 label-in-the-loop alignment，不是更多无标注量"。

论文卖点因此收缩（PR 概率 60-70%→35-45%）。用户裁决：立项新方法研究线强化该卖点，唯一诚实路径=让标签语义（锚点/原型）真正约束伪标签迭代。

## 备选方案

| 方案 | 评估 |
|------|------|
| A. 仅改措辞（把负边界写成贡献） | 否决——回避问题，审稿必炸 |
| B. 新实验线：标签对齐伪标签修正机制 | **采纳**——直接针对已诊断机制，CPU 分钟级可证伪，成败皆诚实 |
| C. 放弃犬科层端到端，转纯组件论文 | 留作 B 失败后的叙事退路 |

## 决策

立项 **P1 线**（编号顺延 P0.x），实现并预注册三个 GT 无关变体（V1 全类锚点共识门 / V2 共识+种子先验配额 / V3 原型路主导迭代）+ V0 对照（R16 原样），主终点=AK v1 spc2×10 seeds 端到端 val top-1，判据跑前冻结（ALIGNS ≥20% 且 ≥8/10 配对胜；PARTIAL 15–20%；NULL <15%）。**协议先于实验冻结**（PSD-ALIGN-PREREG-001）；ALIGNS 才谈 v2/NTU 复现与论文回填，且主张升级须用户再裁（C7 先例）；NULL 则负边界维持，变体研究降级入 §5 作方法学消融。

## 后果

- 新增 `psd/training/tcl_selftrain.py` gate_mode 扩展（默认行为逐字不变，保 P0.4/R16 可复现）+ `scripts/run_p15_align.py`。
- 无论成败都产出可发表的方法学证据：成功=低资源主张复活且有机制解释；失败="标签对齐力单独不足以救此层"的定量边界，与 L9 闭环。
- 禁改已发表/已归档工件；新数字一律新 dated 工件。
