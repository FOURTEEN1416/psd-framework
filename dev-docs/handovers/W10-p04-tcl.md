## 1. 任务目标（一句话）

在 W8 的锚点-原型分配结果之上跑通**迭代自训练闭环**（Algorithm 1 第 4-6 步：训练 Ω → 重分配 → 原型重估），验证伪标签精度随迭代提升，交付 E4 对齐的精度曲线与 P0.5 可用的清洗后伪标签池。

## 2. 直接输入（W8 移交，全部有据）

1. **伪标签池格式**：p03 报告附录 A 的 JSONC 条目结构（含 metric_layer 口径锁字段——**禁止混池**）。
2. **附录 B 三项工程清单（强制执行顺序）**：
   - B-1 margin 校准先行：κ 当前量级 <0.05 不可直接用——softmax(sim/T) 或分位数 z-score 后再设 τ；τ 网格随之重标定；
   - B-2 standing 种子治理第一轮优先：其错误伪标签绝对量最大（逐类精度仅 0.162），用高置信共识清洗或子聚类（K=14 已示受益）；
   - B-3 frequency-aware margin 保持 α=1.0 开启（α=0 留对照行）。
3. **特征缓存复用**：`data/processed/p03/segment_embeddings_<指纹>.npz` 已存在，勿重复抽特征（省 GPU 时）。

## 3. 执行链

### Step 1：Ω 头部训练
- 冻结 Φ 特征上训练轻量分类头（线性层或 2 层 MLP，method §3.3.3 最小可行实现）；TCL 风格时序对比巩固为 stretch goal，不阻塞主线。
- 训练集 = 锚点种子 ∪ 高置信伪标签池（τ_c 过滤后）；评估集沿用 W8 的 clip 级不相交切分（seed=42，防泄漏协议不许改）。

### Step 2：迭代循环（核心交付）
- 每轮：Ω 重分配全量段 → 新 κ → τ_c 过滤入池 → 池并入训练集 → 重训 Ω。
- 迭代预算上限 + 收敛判据写死进 config（防确认偏差跨轮累积，method 设计决策）。

### Step 3：评估（对齐 stage-plan P0.4 验收"对比 P0.3 伪标签精度提升"）
- 主曲线：伪标签池精度（对种子共识真值）与覆盖率随迭代变化；
- 消融：B-2 standing 治理开/关、B-1 校准开/关；
- 统计纪律：≥3 seeds mean±std；诚实披露：本 Phase 真值仍是物理先验伪标签共识，非人工标注（口径锁 public_real_physics_prior）。

### Step 4：归档移交
- `reports/p04-tcl-<日期>.md` + 结果 JSON + 一条命令复现序列；
- 向 P0.5 移交：清洗后伪标签池 + 弱监督训练信号质量结论。
