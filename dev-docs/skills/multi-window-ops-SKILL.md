# Multi-Window Ops — 多窗口 AI 协同作战系统

从 psd-framework 数日实战沉淀。核心命题：**一个仓库 + 一个人类指挥官 + N 个并行 AI 窗口**，如何不打架、不丢信息、不互相等待。

## 角色分工

- **指挥官（人类）**：裁决方向、开窗发命令；不参与中间协调
- **协调者（主窗口）**：规划任务书、验收复核、处理冲突与外部依赖；**不干活只协调**
- **作战窗（N 个）**：领地内自主工作；自助上交、自助拆工地

## 六大机制

### 1. Worktree 物理隔离
每窗一个 git worktree（`../repo-<窗名>` + 分支 `wt/<窗名>`），物理防覆盖。
- 数据目录用 Junction 指向主仓共享；runs/ 各窗独立
- **教训**：runs 独立导致产物滞留孤岛——收编脚本必须含数据汇聚步骤

### 2. 自助收编（消灭协调瓶颈）
窗口完成自检后自己上交，安全靠脚本门禁不靠人治：
```
pwsh scripts/window_checkin.ps1 -Name <窗名> [-Remove] [-Permit 豁免路径]
```
三门禁自动执行：领地扫描（禁触清单命中即拒）→ 窗口内全量测试 → master 合并后回归（失败自动回滚）。合并用 `--no-ff` 留整窗交付节点。冲突自动 abort 上报。

### 3. 跨窗看板（消灭信息不互通）
`dev-docs/board/BOARD.md` 追加只写，全窗共享：
- 开窗第一件事**读看板**；重大发现/移交/阻塞**必须写板**
- 工具：`window_board.ps1 -Append "..." / -Tail N`
- 协调者盯一块板，代替逐窗轮询

### 4. 记忆库双写（补语义盲区）
看板管正式信道（版本化、人类可审）；记忆 MCP 管语义召回（模糊查询即中）：
- 重大发现/裁决：写 BOARD **同时** `memory_add`（agent_id=shared）
- 开工/验收前：`memory_context` / `memory_search` 拉相关记忆
- 双信道缺一不可——文件搜索找不到"没记住关键词"的知识

### 5. 资源接力队列（GPU 等独占资源）
常驻执行器脚本：门禁循环（资源空闲判据 + 持续确认期）→ 严格串行执行队列 → 每步内容级校验（JSON 字段/文件大小/样本量，**非仅存在性**）→ 自动 commit → 失败重试一次 → 再败 HALT 留证停链。
- **教训**：门禁阈值必须适配环境基线（桌面机 GPU 常驻 1.8GB 壁纸/浏览器，`<500MiB` 永不触发）

### 6. 传播矩阵验收（消灭表面验收）
验收 = 逐窗产物验证 **×** 跨窗传播矩阵，后者每发现必答三问：
1. 顺着管线会污染谁？
2. 哪个下游在不知情地消费它？
3. 论文/交付物哪句话会被它打脸？
实例：一个"静态池 GT 缺 4 关节"的盘点发现，追出提点链、微调链、规则引擎、论文措辞四层连带并全部闭环。

## 窗口生命周期

```
开窗：读看板 → 读宪法/HANDOVER → 读本窗任务书 → 领地内工作
完工：自助收编（三门禁）→ 数据汇聚 → 卸窗 → 看板留言走人
阻塞：看板写 BLOCK → 等裁决，不越界自救
```

## 任务书要素（协调者开窗前必写）

目标一句话 / 必读输入清单 / 执行步骤 / **领地边界（可写白名单 + 禁触清单）** / 完成标准（可验证） / 复现命令

## 反模式清单（血泪教训）

- ❌ 验收只查文件存在 + 复算数字 → 漏掉系统性传染（GT 缺 4 关节毒化全链）
- ❌ 门禁阈值拍脑袋 → 桌面基线让队列永不触发
- ❌ 外部标签直接用 → 语义映射错误整列数据作废（序数映射惨案：把 Attacking 当 sit）
- ❌ 占位符复制粘贴 → 过期数字冒充新结果污染论文
- ❌ 负结果藏起来 → 双轮 AL 负结果诚实归档反而成为叙事资产
- ❌ 协调者人肉中转一切 → 窗口完成即闲置，信息靠运气传达
- ❌ 双实例并发写状态文件 → 去重后必须做对账验证
