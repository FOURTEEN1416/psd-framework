# Path-B 最小版预注册草案 — 不对称标注单位的 taxonomy 迁移实验（B-MIN-TRANS）

> 日期: 2026-09-11 · 状态: 🟡 草案（用户裁决 A 先行/B 并行；本文档为 B 最小版设计，未冻结、未执行）
> 动机: 恶意审 Q2 / R35 审计欠账#2——"routine semantic-layer update" 缺一个标注单位不对称的真实数据实验
> 平台: NTU60（管线实现等价性已过预注册线 77.18%，E9 系列协议齐备；不在动物域硬凑）

## 1. 一句话设计

在 NTU60 上造一次 taxonomy 迁移（60→49 合并，复用 TRANS-002 的冻结迁移），两臂标注单位**不对称**：
解耦臂的新 taxonomy 监督**只来自 rule-engine seeds（0 条人工 clip 标签）**；耦合对照臂消费新 taxonomy 的**全量人工重标注**——把"语义层只需规则种子"的经济学主张第一次做实或证伪。

## 2. 三臂

| 臂 | 监督来源 | 标注经济学 | 训练 |
|----|----------|-----------|------|
| D（解耦） | 规则引擎种子（见 §3 规则来源） | **0 人工 clip 标签**（规则运行一次） | 冻结 Φ + 新 taxonomy 头重训（E9-series 解耦配方） |
| C（耦合对照） | 新 taxonomy 全量人工重标注 | 40,091 clip 全标 | 同架构端到端重训（TRANS-002 配方） |
| M（匹配求解器，可选） | 与 D 相同 | 同 D | C 臂冻结倒数第二层特征 + D 的求解器（TRANS-002 M 臂惯例） |

## 3. 规则来源（预研要解决的核心问题）

NTU 分类空间无天然规则引擎（§3.3.2 共识门在数值类空间 inert 的同一事实）。两版候选：
- **方案 a（优先）**：由 Y′ 类定义 + 骨架几何先验人工编写启发式规则（类名语义: 双手类/腿部类/交互类 → 关键点区域+速度阈值），规则文本随工件发布，编写预算记账（估算 <8 工时 ≠ 每clip标注）；
- **方案 b（备选，有循环性风险）**：以 Y 时代基模型高置信预测作为"规则代理"——必须盲评其与 D 臂特征的独立性，或放弃。
- 判据：种子 precision ≥0.5（可训性门槛）；若 <0.5 如实报 FAILS（这本身是边界地图的新点）。

## 4. 预注册判据（草案，冻结前可议）

1. **成本主判据**：D 相对 C 的 wall-clock 比 ≥3×（沿 TRANS-002 惯例）**且** 人工标注量比 ≥10×（40,091 clip vs 规则工时折算）；
2. **精度共判**：D vs C 在 ±2.3pp 等价带内或如实降级 PARTIAL；D 相对 full-supervised reference 的 retention 单列；
3. **负结果条款**：任一判据 FAILS → 写入边界地图（与 E7/E7b/E7c 同格式），不隐藏。

## 5. 预算与机时（估算）

- D 臂: 冻结特征已存在（E9 系列可复用 feature dump）→ 头重训 CPU 级，3 seeds ×分钟级；
- C 臂: 端到端 ST-GCN 重训 3 seeds ≈ 9897s 量级/seed（TRANS-002 同规模）→ **GPU 档 1-2 天机时**；
- M 臂: CPU 分钟级；规则编写 <8 工时人工。
- 总计: **一次 GPU 排期（~2 天）+ 1 人日规则编写**即可出判定；无新数据依赖。
